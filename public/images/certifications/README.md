# Certification Images

Letakkan scan/foto sertifikat resmi di folder ini. Nama file harus
sama dengan `image` di `src/data/certifications.ts`:

- `iso.png` — ISO Certificate
- `ak3.png` — AK3 Certificate
- `competence.png` — Competence Certificate
- `business-entity.png` — Business Entity (SBU) Certificate

Format rekomendasi: **PNG transparan** atau **JPG kualitas tinggi**,
ukuran ≥ 1000px lebar.

Kalau file belum tersedia, sistem akan render placeholder otomatis
(tidak error).
